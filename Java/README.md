# Aula de Java - FIAP

## Checklist de POO - O que já foi aprendido

A partir dos exemplos e exercícios do projeto, os principais conceitos de Programação Orientada a Objetos já praticados foram:

- [x] Criação de classes
- [x] Instanciação de objetos
- [x] Definição de atributos
- [x] Definição de métodos
- [x] Uso do método `main`
- [x] Manipulação de dados e saída no console
- [x] Leitura de dados com `Scanner`
- [x] Cálculo de média e operações matemáticas
- [x] Encapsulamento com `private`, `public` e acesso via getters/setters
- [x] Criação de construtores padrão e com parâmetros
- [x] Validação de informações dentro de métodos
- [x] Controle de estado de objetos (ex.: ligado/desligado, canal/volume)
- [x] Organização do código em pacotes (`aula00`, `aula01`, `aula02`, etc.)
- [x] Exercícios práticos com objetos reais (celular, carro, televisão, personagem)
